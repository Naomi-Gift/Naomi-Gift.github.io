About

I am a Btrust fellow working on Bitcoin's open-source software full time.

Since September I have opened 22 pull requests in five Bitcoin projects: rbitcoin, Bitcoin Core, Core Lightning, BDK and fungi. 11 are merged and 6 are in review. I have reviewed and tested 7 pull requests in Bitcoin Core and BDK, and written 5 articles on Bitcoin and Lightning.

I work test-first. Before I fix a bug I write a test that fails, and when I review I put the bug back to check that the test notices.

Selected work
rbitcoin · 2026

Private broadcast that doesn't leak your IP ↗

Sending your own transaction over Tor so no one can link it to you. I closed a leak where the node could dial a clearnet peer directly, made delivery wait for the peer's pong, ended the broadcast once the network echoes the transaction back, and added retries up to Core's limit of 1,000.

RustTorP2P4 PRs merged
rbitcoin · 2026

Onion and I2P services that survive restarts ↗

When Tor or i2pd restarted, the node's hidden addresses died until a manual restart. Now the node notices, stops announcing the dead address, reconnects with Core's backoff and restores every service. Tested against real Tor, real i2pd and Bitcoin Core 29.

RustTor controlI2P SAM2 PRs merged
Bitcoin Core · 2026

Tests that kill surviving mutants in coin selection ↗

A mutant is a small bug put in on purpose. If every test still passes, that line is unguarded. I wrote tests for four of them, including one where the wallet would add a fee discount instead of subtracting it and overpay.

C++wallet2 ACKs
BDK · 2026

A wallet that checks the signatures it finalizes ↗

BDK skipped signing an input that already had a signature, without checking it, so a PSBT could finalize with an invalid one. The wallet now always writes a fresh, verified signature for ECDSA and both Taproot paths.

RustPSBTTaproottACK
Core Lightning · 2026

A first gossip sync that finishes ↗

A fresh Lightning node could stop syncing early and never learn the network's channels. I checked the three reported causes against master. All three held, and one PR fixes them.

CLightninggossip
rbitcoin · 2026

RPC answers that match Bitcoin Core ↗

Wallets and explorers break when a node answers differently from Core. I added Core's output descriptors to six RPC calls, fixed error codes, and made getnetworkinfo report the networks the node really uses.
